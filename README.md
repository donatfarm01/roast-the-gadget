One original line roasting a gadget used every day, written for the
make.fun bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`.

## The entry

> My phone charger only works at one exact angle, so I charge my phone like I'm defusing a bomb.

94 characters, one line, no trailing newline.

## How it works

`main.py` writes that line to `/output/entry.txt`. Before writing it checks
the gate from the kit rules: UTF-8 text of 1 to 200 characters, not only
white space, a single line, and a single sentence (no hidden second sentence
behind an exclamation mark, a question mark, or an extra full stop). After
writing it reads the file back and confirms the bytes on disk are exactly
the text that was checked. The program runs on Python 3.13 with no
dependencies and no network access.
